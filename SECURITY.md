# Security policy

## Supported versions

The latest `0.1.x` release is the only supported line while the project is experimental.

## Reporting a vulnerability

Please do not publish an exploitable vulnerability in a public issue. Contact the repository maintainers privately through the security contact configured on the GitHub repository. Include a description, affected version, reproduction steps, and impact. Do not include secrets or private source documents in a report.

If no private contact has been configured yet, open a minimal issue asking for a security contact without exploit details.

EvidenceBench processes user documents locally by default. See [docs/security.md](docs/security.md) for the threat model, prompt-injection handling, and risks of adding remote providers.
