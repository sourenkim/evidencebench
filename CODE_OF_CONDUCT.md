# Code of Conduct

We want EvidenceBench to be a respectful, useful project for everyone.

Participants are expected to:

- be respectful and constructive;
- assume good faith while discussing technical disagreements;
- focus criticism on ideas and code, not people;
- welcome different backgrounds and levels of experience;
- avoid harassment, discrimination, personal attacks, and unwanted contact.

Maintainers may remove comments, close discussions, or restrict participation when behavior violates these expectations. Report concerns privately to the maintainers using the process in `SECURITY.md` when they involve safety or abuse.
