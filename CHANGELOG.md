# Changelog

All notable changes to EvidenceBench are documented here.

## [0.1.0] - 2026-09-20

- Initial local-first CLI and typed evaluation pipeline.
- TXT and Markdown ingestion with optional PDF extraction.
- Deterministic claim segmentation, lexical retrieval, and claim evaluation.
- Claim-level statuses, transparent metrics, threshold assertions, JSON, terminal, and static HTML reports.
- Original 20-document, 100-case, 480-claim benchmark dataset.
- Offline tests, lint/type-check configuration, security documentation, and CI.
