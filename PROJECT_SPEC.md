# EvidenceBench Project Specification

Version: 0.1.0
Status: experimental, local-first CLI

## Purpose

EvidenceBench is an open-source testing framework for measuring whether AI-generated answers are supported by source documents. It treats an answer as a set of independently evaluated claims and preserves uncertainty instead of collapsing every result into true/false.

## MVP contract

The 0.1.0 release provides:

- local ingestion for TXT and Markdown, with optional PDF support through `pypdf`
- deterministic claim segmentation suitable for baselines and regression tests
- deterministic lexical evidence retrieval
- an evaluation model with `SUPPORTED`, `PARTIALLY_SUPPORTED`, `UNSUPPORTED`, and `INSUFFICIENT_EVIDENCE`
- transparent metrics, JSON output, a no-JavaScript HTML report, and terminal output
- threshold assertions for CI
- provider protocols for future model-based claim extraction, retrieval, and evaluation
- a small original benchmark dataset and a reproducible benchmark command

The default pipeline makes no network calls and requires no API key.

## Non-goals

The MVP is not a general chatbot, a factuality oracle, a hosted service, a replacement for human review, or a claim that lexical matching understands meaning. Model-backed providers and learned embeddings are extension points, not hidden dependencies.

## Quality bar

Every metric has a documented definition and tests. Every benchmark number is generated by the repository's benchmark command. Source locations are preserved only when extraction provides them. Source-document instructions are always treated as data.
