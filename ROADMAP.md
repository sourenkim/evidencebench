# Roadmap

## 0.1.0 (current)

Local-first deterministic evaluation for TXT/Markdown, optional PDF extraction, claim-level statuses, metrics, JSON/terminal/static HTML reports, threshold assertions, a reproducible original benchmark, and provider protocols.

## 0.2

Additional document formats, stronger sentence and citation parsing, configurable retrieval strategies, richer location validation, and dataset authoring tools.

## 0.3

RAG retrieval-set evaluation, experiment tracking, model comparison, and optional semantic evaluators.

## 0.4

A maintained GitHub Action, a web dashboard, and documented adapters for additional providers.

## Future

Local embedding models, human-in-the-loop annotation, dataset management, statistical confidence intervals, multilingual evaluation, and specialized contradiction analysis.
